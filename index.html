🎬 GIF → Sticker animado de WhatsApp

Selecciona cualquier GIF. La herramienta conserva su proporción y no lo recorta a cuadrado. El resultado será un WebP animado.

⚠️ Estás abriendo este HTML como archivo.
Chrome/Brave bloquea el motor necesario para convertir GIF porque necesita un Web Worker. Para que funcione, el HTML debe abrirse desde http:// o https:// (por ejemplo, GitHub Pages).
ℹ️ Importante

Esta herramienta genera un WebP animado. Para que el conversor funcione, abre este HTML desde una dirección http/https; no desde file://. WhatsApp aplica sus propios límites al importar stickers (duración, tamaño de archivo y otros parámetros), por lo que un GIF muy grande puede necesitar una reducción de FPS o tamaño. La opción “sin recortar” conserva la relación de aspecto.

La conversión se ejecuta en el navegador. Para realizar la codificación se carga FFmpeg WebAssembly desde un CDN; la primera conversión puede tardar y requiere conexión a Internet.
